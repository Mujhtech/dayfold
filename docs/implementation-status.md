# Implementation status

Updated 7 November 2026. M00–M11 have a working development implementation, a real macOS app, deterministic regression coverage, and local archive evidence. **Core is not yet verified for beta.** The [185-case acceptance map](acceptance.md) records partial and missing evidence explicitly; a compiled feature is not a passed acceptance case.

**Public multi-user release is blocked by the [security requirements](security.md).** The relay now implements OIDC user identity, device-key enrollment, DPoP access, token expiry/rotation and account/device revocation. Real identity-provider and signed-Mac acceptance, verified push-destination possession and deployment controls remain open; public user sessions cannot register APNs destinations.

The owner selected the M12 notification backend and native integration. A separate Rust workspace implements a PostgreSQL-backed change-hint relay, live inbox streaming, scheduled reminders and an APNs adapter. The Mac provides account sign-in/device management, Keychain session recovery, Google watch creation/renewal, durable SSE replay, reminder ownership/claims and notification routing. APNs destination registration is currently limited to local legacy tests until public possession verification is implemented. Local Swift → Rust → PostgreSQL integration passes with simulated Google callbacks and notification delivery. Public deployment and actual Google/APNs/Notification Center delivery remain unverified; see [native setup](relay.md) and [backend protocol](../backend/README.md). Busy mirroring, split-series edits, other providers, updater and billing are not enabled.

See [verification.md](verification.md) for exact commands, measurements and manual records; [setup.md](setup.md) for OAuth prerequisites; [release.md](release.md) for the local archive and distribution boundary. Logs under `.build/evidence` are local development evidence and are ignored by git. Checked-in screenshots use only fictional data.
